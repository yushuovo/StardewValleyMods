# ChestPeek

ChestPeek is a Stardew Valley SMAPI mod that previews chest contents when hovering over a chest.

## Features

- Preview chest contents without opening the chest.
- Optional hotkey-based preview mode.
- Optional time-freeze behavior while previewing in single-player.
- In-game configuration support through Generic Mod Config Menu, if installed.

## Requirements

- Stardew Valley
- SMAPI

## Installation

1. Install SMAPI.
2. Download the latest ChestPeek release.
3. Extract the mod folder into your Stardew Valley `Mods` folder.
4. Launch the game through SMAPI.

## Configuration

After launching the game once, the mod will generate a `config.json` file automatically.

If Generic Mod Config Menu is installed, the configuration can also be changed in-game.

## Compatibility

This mod is designed for Stardew Valley with SMAPI.
