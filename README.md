# Stardew Valley Mods

A collection of my Stardew Valley SMAPI mods.

## Mods

| Mod | Description | Status |
| --- | --- | --- |
| [ChestPeek](./ChestPeek) | Preview chest contents by hovering over chests. | Released |

## Requirements

- Stardew Valley
- SMAPI
- .NET 6 SDK for development

## Installation

Each mod has its own installation instructions in its folder.

For normal players, download the release package of the specific mod and place the extracted folder into the Stardew Valley `Mods` directory.

## Development

This repository is organized as a multi-mod workspace.

Open the solution file:

```text
StardewValleyMods.sln
```

Each mod is stored in its own folder and can be built independently.
